## 📋 Descrição do Portfólio
Este projeto consiste no desenvolvimento de um portfólio web pessoal e profissional, criado para apresentar a trajetória acadêmica, habilidades técnicas e principais projetos desenvolvidos na área de tecnologia e desenvolvimento de sistemas. O layout foi pensado seguindo uma identidade visual moderna (Dark Mode com detalhes neon).

## 🚀 Tecnologias Utilizadas
* **HTML5 / CSS3**: Estruturação semântica e estilização customizada.
* **Bootstrap 5.3**: Framework CSS responsivo para estruturação de componentes, grid e navegação.
* **JavaScript**: Interatividade do menu e elementos dinâmicos.
* **Google Fonts & Bootstrap Icons**: Tipografia moderna e iconografia integrada.
* **GitHub Pages**: Hospedagem e publicação contínua da aplicação.

## ⚙️ Explicação do Funcionamento do Projeto
O site é estruturado em uma página única (*Single Page Application* com navegação por âncoras), dividida nas seguintes seções principais:
1. **Menu de Navegação:** Fixo no topo (`fixed-top`), permitindo transição fluida entre as seções.
2. **Seção de Perfil:** Apresentação pessoal com destaque para o curso e objetivos.
3. **Seção de Habilidades:** Cards informativos detalhando a stack técnica.
4. **Seção de Projetos:** Vitrine em grid responsiva contendo os principais trabalhos realizados.
5. **Seção de Contato:** Acesso direto às redes profissionais e e-mail.

## ✨ Descrição do Recurso Novo Adicionado
Além dos requisitos base solicitados (Perfil, Projetos, Contato, Menu Responsivo e Bootstrap), foi adicionada uma **Seção dedicada de Habilidades** estruturada em cards interativos com efeitos visuais avançados de *hover* (elevação suave e alteração de borda em destaque neon).

## 🛠️ Explicação de Como Esse Recurso Foi Implementado
O recurso novo foi construído combinando o sistema de grid do Bootstrap (`g-4`, `col-md-4`) com propriedades customizadas de CSS moderno:
* Utilização de transições suaves (`transition: transform 0.3s ease, border-color 0.3s ease;`).
* Efeito de deslocamento no eixo Y combinado com brilho de borda (`transform: translateY(-5px); border-color: #38bdf8;`) ativado no estado `:hover` dos cards.
